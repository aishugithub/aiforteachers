Apps Script Lab: four school jobs, done in one click

Four everyday situations from school, each with sample data, a ready script and the exact steps to run it. The last one publishes your mark list as a web page. Do them along with the demo, then change the data to your own.

You need: a Google account and a laptop Time: about 10 minutes per sample Start at: sheets.new

Every sample, the same way

The 6 moves

  1. Open a SheetGo to sheets.new.
  2. Paste the dataClick Copy data below, click cell A1, press Ctrl+V.
  3. Open the editorExtensions → Apps Script. A new tab opens.
  4. Paste the scriptDelete what's there, paste, click 💾 Save.
  5. RunPick the function in the drop-down at the top and click ▷ Run.
  6. Allow, onceReview permissions → your account → Advanced → Go to … (unsafe) → Allow.

Why "unsafe"? Google shows this for every script that you write yourself, because Google hasn't reviewed it. It's safe here because it's your script and you can read what it does. Never allow a script from someone you don't know.

Watch the right tab. Messages from the script (small pop-ups at the bottom right) appear in the Sheet tab, not in the editor. The editor shows progress in the Execution log.

Sample 1 · Exam cell

Exam timetable → Google Calendar

The situation: the Term 1 timetable for Class 9A is ready in a Sheet. Every teacher and student needs it in their calendar, with a reminder the evening before. Typing five events by hand is slow, and typing them for twelve sections is a whole afternoon.

Sample data: paste into cell A1

Date	Start	End	Class	Subject	Room	Status
2026-11-16	09:30	12:30	9A	Mathematics	Room 12
2026-11-17	09:30	12:30	9A	Science	Room 12
2026-11-18	09:30	12:30	9A	English	Room 12
2026-11-19	09:30	11:30	9A	Social Science	Room 14
2026-11-20	09:30	11:30	9A	Tamil	Room 14

Script

/**
 * Exam timetable -> Google Calendar.
 *
 * Sheet layout (row 1 = headings, one exam per row):
 *   Date | Start | End | Class | Subject | Room | Status
 * Every exam goes into a calendar called "Term 1 Exams" (made if missing), with a
 * reminder the day before. Rows already marked "Added" are skipped, so it is safe
 * to run again after adding more exams.
 *
 * Use: Extensions > Apps Script, paste this, Save, then Run "addExamsToCalendar".
 * After the first run there is also an "Exams" menu in the Sheet.
 */

var CALENDAR_NAME = 'Term 1 Exams';
var REMIND_MINUTES_BEFORE = 24 * 60;   // one day

function onOpen() {
  SpreadsheetApp.getUi().createMenu('Exams')
    .addItem('Add exams to Calendar', 'addExamsToCalendar')
    .addToUi();
}

function addExamsToCalendar() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  var range = sheet.getDataRange();
  var values = range.getValues();          // dates as real dates
  var shown = range.getDisplayValues();    // times as typed, e.g. 09:30
  var tz = ss.getSpreadsheetTimeZone();

  var cal = CalendarApp.getCalendarsByName(CALENDAR_NAME)[0] || CalendarApp.createCalendar(CALENDAR_NAME);
  var added = 0;

  for (var i = 1; i < values.length; i++) {
    var r = values[i], s = shown[i];
    if (!r[0] || String(r[6]).indexOf('Added') === 0) continue;   // empty or done

    var day = r[0] instanceof Date ? Utilities.formatDate(r[0], tz, 'yyyy-MM-dd') : toIsoDate_(s[0], i);
    var start = Utilities.parseDate(day + ' ' + toTime_(s[1], i), tz, 'yyyy-MM-dd HH:mm');
    var end = Utilities.parseDate(day + ' ' + toTime_(s[2], i), tz, 'yyyy-MM-dd HH:mm');

    var event = cal.createEvent(r[3] + ' ' + r[4] + ' exam', start, end, {
      location: String(r[5]),
      description: 'Class ' + r[3] + ' · ' + r[4] + ' · Room ' + r[5]
    });
    event.removeAllReminders();
    event.addPopupReminder(REMIND_MINUTES_BEFORE);

    sheet.getRange(i + 1, 7).setValue('Added ✓');
    added++;
  }
  ss.toast(added + ' exam(s) added to the "' + CALENDAR_NAME + '" calendar.', 'Exams', 10);
}

/** "9:30", "09:30:00" or "2:00 PM" -> "HH:mm". */
function toTime_(text, i) {
  var m = /(\d{1,2})[:.](\d{2})(?::\d{2})?\s*([ap])?/i.exec(text);
  if (!m) throw new Error('Row ' + (i + 1) + ': the time "' + text + '" is not like 09:30.');
  var h = parseInt(m[1], 10);
  if (m[3] && /p/i.test(m[3]) && h < 12) h += 12;
  if (m[3] && /a/i.test(m[3]) && h === 12) h = 0;
  return (h < 10 ? '0' : '') + h + ':' + m[2];
}

/** A date typed as text: 2026-11-16 or 16/11/2026 (day first, as in India). */
function toIsoDate_(text, i) {
  var m = /^(\d{4})-(\d{1,2})-(\d{1,2})$/.exec(text) || /^(\d{1,2})[\/.-](\d{1,2})[\/.-](\d{4})$/.exec(text);
  if (!m) throw new Error('Row ' + (i + 1) + ': the date "' + text + '" is not like 2026-11-16.');
  var y = m[1].length === 4 ? m[1] : m[3], mo = m[2], d = m[1].length === 4 ? m[3] : m[1];
  return y + '-' + ('0' + mo).slice(-2) + '-' + ('0' + d).slice(-2);
}
  1. Do the 6 moves. In the drop-down, choose addExamsToCalendar.
  2. Open Google Calendar and go to the week of 16 November 2026.

You should see: a new calendar called Term 1 Exams in the left list, five exam events with the room as location, and a reminder one day before each. In the Sheet, the Status column says Added ✓. Run it again and nothing is added twice.

Share it: in Calendar, open the ⋮ next to Term 1 Exams → Settings and sharing → share with your colleagues, or get the public link for students and parents.

After the demo: to remove everything, open the ⋮ next to Term 1 Exams → Settings and sharing → Remove calendar. Your own calendar is not touched.

Script

/**
 * Certificates in one click.
 *
 * Sheet layout (row 1 = headings, one student per row):
 *   Name | Class | Event | Position | Date | Certificate
 * The first run makes a certificate template in Google Docs (you can edit its
 * wording and design). Each row then becomes a PDF in a Drive folder called
 * "Certificates", and its link goes in the Certificate column. Rows that
 * already have a link are skipped.
 *
 * Template placeholders: {{Name}} {{Class}} {{Event}} {{Position}} {{Date}}
 *
 * Use: Extensions > Apps Script, paste this, Save, then Run "makeCertificates".
 * After the first run there is also a "Certificates" menu in the Sheet.
 */

var SCHOOL_NAME = 'Your School Name';   // change to your school
var FOLDER_NAME = 'Certificates';

function onOpen() {
  SpreadsheetApp.getUi().createMenu('Certificates')
    .addItem('Make certificates', 'makeCertificates')
    .addItem('Open the template', 'openTemplate')
    .addToUi();
}

function makeCertificates() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  var values = sheet.getDataRange().getDisplayValues();
  var template = DriveApp.getFileById(getTemplateId_());
  var folder = getFolder_(FOLDER_NAME);
  var made = 0;

  for (var i = 1; i < values.length; i++) {
    var r = values[i];
    if (!r[0] || r[5]) continue;   // no name, or already made

    var copy = template.makeCopy(r[0] + ' - ' + r[2], folder);
    var doc = DocumentApp.openById(copy.getId());
    var body = doc.getBody();
    ['Name', 'Class', 'Event', 'Position', 'Date'].forEach(function (key, k) {
      body.replaceText('\\{\\{' + key + '\\}\\}', r[k]);
    });
    doc.saveAndClose();

    var pdf = folder.createFile(copy.getAs('application/pdf')).setName(r[0] + ' - ' + r[2] + '.pdf');
    copy.setTrashed(true);   // keep only the PDF
    sheet.getRange(i + 1, 6).setValue(pdf.getUrl());
    made++;
    ss.toast(made + ' certificate(s) made...', 'Certificates', 5);
  }
  ss.toast(made + ' certificate(s) saved in the "' + FOLDER_NAME + '" folder in Drive.', 'Certificates', 10);
}

function openTemplate() {
  var url = DocumentApp.openById(getTemplateId_()).getUrl();
  SpreadsheetApp.getActiveSpreadsheet().toast('Template: ' + url, 'Certificates', 20);
  Logger.log('Template: ' + url);
}

/** The template's ID is remembered in this Sheet. If it's missing or deleted, make a new one. */
function getTemplateId_() {
  var props = PropertiesService.getDocumentProperties();
  var id = props.getProperty('templateId');
  if (id) {
    try { if (!DriveApp.getFileById(id).isTrashed()) return id; } catch (e) { /* deleted */ }
  }
  id = createTemplate_();
  props.setProperty('templateId', id);
  return id;
}

/** A simple landscape A4 certificate. Edit the Doc afterwards to change the design. */
function createTemplate_() {
  var doc = DocumentApp.create('Certificate template');
  var body = doc.getBody();
  body.setPageWidth(842).setPageHeight(595)
    .setMarginTop(60).setMarginBottom(40).setMarginLeft(72).setMarginRight(72);
  body.clear();

  var lines = [
    [SCHOOL_NAME, 20, true, '#16223D'],
    ['CERTIFICATE OF ACHIEVEMENT', 30, true, '#2A54C8'],
    ['This is to certify that', 14, false, '#4B5A7A'],
    ['{{Name}}', 34, true, '#16223D'],
    ['of Class {{Class}}, for {{Position}} in {{Event}}', 16, false, '#16223D'],
    ['held on {{Date}}.', 14, false, '#4B5A7A'],
    ['', 30, false, '#16223D'],
    ['Class Teacher                                                                Principal', 13, true, '#16223D']
  ];
  lines.forEach(function (l, k) {
    var p = k === 0 ? body.getParagraphs()[0].setText(l[0]) : body.appendParagraph(l[0]);
    p.setAlignment(DocumentApp.HorizontalAlignment.CENTER).setSpacingAfter(10)
      .editAsText().setFontSize(l[1]).setBold(l[2]).setForegroundColor(l[3]).setFontFamily('Georgia');
  });
  doc.saveAndClose();
  return doc.getId();
}

function getFolder_(name) {
  var found = DriveApp.getFoldersByName(name);
  return found.hasNext() ? found.next() : DriveApp.createFolder(name);
}
  1. In the script, change SCHOOL_NAME on line 17 to your school's name. Save.
  2. Do the 6 moves. In the drop-down, choose makeCertificates. It takes a few seconds per student.
  3. Open Google Drive → the Certificates folder.

You should see: five PDF certificates, one per student, named like Aarav Kumar - the Inter-house Quiz 2026.pdf. The Certificate column in the Sheet now has a link to each one.

Make it yours: the first run also creates a Google Doc called Certificate template in your Drive. Open it and change the wording, fonts or colours, or add the school logo. Keep the words in {{ }} as they are. Then clear the Certificate column and run again.

Names are personal data. A certificate needs the student's name, so keep this Sheet and the Certificates folder in your school account and share them only with the staff who need them.

Script

/**
 * Unit-test marks analysis.
 *
 * Sheet layout (row 1 = headings): Roll No | Subject 1 | Subject 2 | ...
 * Marks out of 100. Any number of subjects. Use roll numbers, not names.
 * Makes a "Summary" tab: average, highest, lowest and pass % per subject, who is
 * below the pass mark in each subject, a remedial list (below the pass mark in
 * two or more subjects) and a chart. Marks below the pass mark turn pink.
 *
 * Use: Extensions > Apps Script, paste this, Save, then Run "analyseMarks".
 * After the first run there is also a "Marks" menu in the Sheet.
 */

var PASS_MARK = 35;

function onOpen() {
  SpreadsheetApp.getUi().createMenu('Marks')
    .addItem('Analyse marks', 'analyseMarks')
    .addToUi();
}

function analyseMarks() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  if (sheet.getName() === 'Summary') throw new Error('Click the marks tab first, then run again.');

  var values = sheet.getDataRange().getValues();
  var subjects = values[0].slice(1);
  var students = values.slice(1).filter(function (r) { return r[0] !== ''; });
  if (!students.length) throw new Error('No marks found. Put headings in row 1: Roll No, then one column per subject.');

  // Per-subject statistics, and who is below the pass mark.
  var stats = [['Subject', 'Average', 'Highest', 'Lowest', 'Pass %', 'Below ' + PASS_MARK + ' (roll numbers)']];
  var fails = {};   // roll number -> subjects below the pass mark
  subjects.forEach(function (subject, s) {
    var marks = [], below = [];
    students.forEach(function (r) {
      var m = r[s + 1];
      if (typeof m !== 'number') return;   // absent or blank
      marks.push(m);
      if (m < PASS_MARK) {
        below.push(r[0]);
        (fails[r[0]] = fails[r[0]] || []).push(subject);
      }
    });
    var sum = marks.reduce(function (a, b) { return a + b; }, 0);
    stats.push([subject,
      marks.length ? Math.round(sum / marks.length * 10) / 10 : '',
      marks.length ? Math.max.apply(null, marks) : '',
      marks.length ? Math.min.apply(null, marks) : '',
      marks.length ? Math.round((marks.length - below.length) / marks.length * 100) + '%' : '',
      below.join(', ') || 'None']);
  });

  var remedial = [['Roll No', 'Subjects below ' + PASS_MARK]];
  Object.keys(fails).forEach(function (roll) {
    if (fails[roll].length >= 2) remedial.push([roll, fails[roll].join(', ')]);
  });
  if (remedial.length === 1) remedial.push(['None', '']);

  // Write the Summary tab from scratch each time.
  var out = ss.getSheetByName('Summary') || ss.insertSheet('Summary');
  out.clear();
  out.getCharts().forEach(function (c) { out.removeChart(c); });
  out.getRange(1, 1).setValue('Marks summary · ' + students.length + ' students · pass mark ' + PASS_MARK)
    .setFontSize(14).setFontWeight('bold');
  out.getRange(3, 1, stats.length, stats[0].length).setValues(stats);
  out.getRange(3, 1, 1, stats[0].length).setFontWeight('bold').setBackground('#E3EBFD');

  var rRow = stats.length + 5;
  out.getRange(rRow - 1, 1).setValue('Remedial group: below the pass mark in two or more subjects').setFontWeight('bold');
  out.getRange(rRow, 1, remedial.length, 2).setValues(remedial);
  out.getRange(rRow, 1, 1, 2).setFontWeight('bold').setBackground('#FDE2E6');
  out.autoResizeColumns(1, stats[0].length);

  out.insertChart(out.newChart()
    .setChartType(Charts.ChartType.COLUMN)
    .addRange(out.getRange(3, 1, stats.length, 2))
    .setPosition(3, 8, 0, 0)
    .setOption('title', 'Class average by subject')
    .setOption('legend', { position: 'none' })
    .setOption('vAxis', { minValue: 0, maxValue: 100 })
    .build());

  // Pink background on every mark below the pass mark in the marks tab.
  var markRange = sheet.getRange(2, 2, values.length - 1, subjects.length);
  var colours = markRange.getValues().map(function (row) {
    return row.map(function (m) { return typeof m === 'number' && m < PASS_MARK ? '#FDE2E6' : null; });
  });
  markRange.setBackgrounds(colours);

  ss.toast('Summary ready: ' + (remedial[1][0] === 'None' ? 0 : remedial.length - 1) + ' student(s) in the remedial group.', 'Marks', 10);
}
  1. Do the 6 moves. In the drop-down, choose analyseMarks.
  2. Go back to the Sheet tab.

You should see: every mark below 35 is now pink. A new Summary tab shows the average, highest, lowest and pass % for each subject, the roll numbers below 35 in each subject, a remedial group (9A04, 9A06 and 9A11 are below 35 in two or more subjects) and a column chart of the averages. "AB" (absent) is left out of the calculations.

Try changing: set PASS_MARK to 40 on line 14, Save, and run again. The Summary is rebuilt each time. Add a sixth subject column and it's included automatically.

Check it like any AI output: work out one subject's average yourself and compare. Once you have checked a script, it gives the same right answer every time.

Sample 4 · Deploy as a web app

The mark list as a web page

The situation: the HOD and the class teacher want to see Class 9A's marks on their phones during the parent-teacher meeting, without opening the spreadsheet. Publish the Sheet as a small web page: one link that always shows the latest marks.

Use the same Sheet as Sample 3, or paste the Sample 3 data into a new Sheet. If you already have Sample 3's script, click ＋ → Script in the editor and paste this as a second file.

Script

/**
 * The mark list as a web page.
 *
 * Uses the same Sheet as the marks analysis sample:
 *   Roll No | Subject 1 | Subject 2 | ...   (marks out of 100, roll numbers only)
 * The page shows every mark (below the pass mark in pink), each student's total and
 * percentage, the class average per subject and a search box for a roll number.
 * It reads the Sheet each time it opens, so a refresh shows the latest marks.
 *
 * Use: Extensions > Apps Script, paste this, Save. Then Deploy > New deployment >
 * Web app. Execute as: Me. Who has access: Only myself, or your school only.
 * Never "Anyone": this page shows marks.
 */

var PAGE_PASS_MARK = 35;
var PAGE_TITLE = 'Class 9A · Unit Test 1 marks';

function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheets().filter(function (s) { return s.getName() !== 'Summary'; })[0];
  var values = sheet.getDataRange().getValues();
  var subjects = values[0].slice(1);
  var students = values.slice(1).filter(function (r) { return r[0] !== ''; });

  var rows = students.map(function (r) {
    var marks = r.slice(1), total = 0, count = 0;
    var cells = marks.map(function (m) {
      if (typeof m !== 'number') return '<td class="ab">' + esc_(m || '-') + '</td>';
      total += m; count++;
      return '<td' + (m < PAGE_PASS_MARK ? ' class="low"' : '') + '>' + m + '</td>';
    }).join('');
    var pct = count ? Math.round(total / count) + '%' : '-';
    return '<tr><th scope="row">' + esc_(r[0]) + '</th>' + cells + '<td class="t">' + total + '</td><td class="t">' + pct + '</td></tr>';
  }).join('');

  var averages = subjects.map(function (s, k) {
    var marks = students.map(function (r) { return r[k + 1]; }).filter(function (m) { return typeof m === 'number'; });
    var sum = marks.reduce(function (a, b) { return a + b; }, 0);
    return '<td>' + (marks.length ? Math.round(sum / marks.length * 10) / 10 : '-') + '</td>';
  }).join('');

  var html =
    '<style>' +
    'body{font:16px/1.5 system-ui,sans-serif;margin:0;padding:20px;background:#F5F8FC;color:#16223D}' +
    'h1{font-size:1.6rem;margin:0 0 4px}p{margin:0 0 14px;color:#4B5A7A}' +
    'input{font:inherit;padding:8px 12px;border:1px solid #D3DDEB;border-radius:8px;width:220px;margin-bottom:14px}' +
    '.wrap{overflow-x:auto;background:#fff;border:1px solid #D3DDEB;border-radius:12px}' +
    'table{border-collapse:collapse;width:100%}th,td{padding:8px 12px;border-bottom:1px solid #E3EAF4;text-align:center}' +
    'thead th{background:#E3EBFD}tbody th{text-align:left}td.low{background:#FDE2E6;color:#A33A45;font-weight:700}' +
    'td.ab{color:#8792A8}td.t{font-weight:700}tfoot td,tfoot th{background:#DDF5E6;font-weight:700}' +
    '</style>' +
    '<h1>' + esc_(PAGE_TITLE) + '</h1>' +
    '<p>' + students.length + ' students · pink = below ' + PAGE_PASS_MARK + ' · updated ' +
    Utilities.formatDate(new Date(), ss.getSpreadsheetTimeZone(), 'd MMM yyyy, h:mm a') + '</p>' +
    '<input id="q" placeholder="Search roll number" oninput="find(this.value)">' +
    '<div class="wrap"><table><thead><tr><th>Roll No</th>' +
    subjects.map(function (s) { return '<th>' + esc_(s) + '</th>'; }).join('') +
    '<th>Total</th><th>%</th></tr></thead><tbody>' + rows + '</tbody>' +
    '<tfoot><tr><th>Class average</th>' + averages + '<td></td><td></td></tr></tfoot></table></div>' +
    '<script>function find(q){q=q.trim().toUpperCase();document.querySelectorAll("tbody tr").forEach(function(tr){' +
    'tr.style.display=tr.firstChild.textContent.toUpperCase().indexOf(q)>=0?"":"none";});}</script>';

  return HtmlService.createHtmlOutput(html)
    .setTitle(PAGE_TITLE)
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

function esc_(v) {
  return String(v).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
}
  1. Paste the script and click 💾 Save. There's nothing to Run this time.
  2. Click the blue Deploy button (top right) → New deployment.
  3. Click the ⚙️ gear next to Select type → Web app.
  4. Description: Mark list. Execute as: Me. Who has access: Only myself for the demo.
  5. Click Deploy, then Authorize access and allow, as in the 6 moves.
  6. Copy the Web app URL and open it in a new tab, or on your phone.

You should see: a page titled Class 9A · Unit Test 1 marks with every student's marks, total and percentage, marks below 35 in pink, the class average at the bottom, and a box to search for a roll number. Now change a mark in the Sheet and refresh the page: the new mark is there.

Who has access matters. Only myself: just you. Anyone within [your school]: only people signed in with a school account, which is right for staff. Never choose Anyone for marks: anyone with the link could see them, with no sign-in.

Changed the script? The link keeps showing the old version until you click Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy. The link stays the same. Changes to the marks show straight away; only changes to the script need this.

Make it yours: change PAGE_TITLE and PAGE_PASS_MARK at the top of the script. Ask an AI to add more, for example "add a column chart of the class averages at the top of the page".

Deploy

Share it and make it run by itself

Sample 4 showed one way to deploy: a web app. Here are three more ways to put a script to work.

1 · A menu in the Sheet

After the first run, reload the Sheet. A new menu (Exams, Certificates or Marks) appears next to Help. From now on, you or a colleague can run the script from the menu without opening the editor.

2 · Give it to every teacher

  1. Clear the sample rows and leave the headings. Rename the Sheet, for example Marks analysis – make a copy.
  2. Click Share, give colleagues Viewer access and send the link.
  3. Each teacher opens it and clicks File → Make a copy. The script is copied too.
  4. They paste their own data, run it from the menu and allow the permissions once.

Why a copy? Each teacher gets their own Sheet, their own data and their own calendar or folder. Nobody can change your original by mistake.

3 · Make it run on a timer (triggers)

  1. In the editor, click the ⏰ Triggers icon on the left → Add trigger.
  2. Choose the function (for example analyseMarks), event source Time-driven, then Week timer → Every Friday, 4 pm to 5 pm.
  3. Save. Every Friday the Summary is rebuilt from that week's marks.

Other triggers: From spreadsheet → On form submit runs a script each time a Google Form linked to the Sheet gets a response, for example to send a thank-you email.

Keep the marks tab first. A timer has no "current tab", so the script uses the first tab. If you add a trigger to the marks sample, keep the marks tab first (drag the Summary tab to the right).

Write once, check once, use all year.

If something goes wrong

"Exceeded maximum execution time"

A script can run for up to 6 minutes at a time. These samples don't open pop-ups that wait for you, so this should only happen with very long lists. Split the list into two Sheets, or just run it again: rows already done (Added ✓ or a certificate link) are skipped.

Nothing seems to happen

Look at the Sheet tab, not the editor: the messages appear at the bottom right of the Sheet. In the editor, the Execution log shows "Execution completed" when it's done.

The data went into one cell instead of columns

Use the Copy data button and paste with Ctrl+V into cell A1. If it still lands in column A, choose Data → Split text to columns and pick Tab as the separator.

"Row 3: the time … is not like 09:30"

In the exam sample, type times as 09:30 or 2:00 PM and dates as 2026-11-16 or 16/11/2026. Fix that cell and run again.

"This app is blocked" or Apps Script won't open

On a school (Workspace) account, the admin may have switched Apps Script off or blocked unverified scripts. Ask your admin, or practise with a personal account and sample data only.

Can I ask an AI to change a script?

Yes. Paste the script into Gemini, ChatGPT or Claude and describe the change, for example "also email the Summary to me every Friday". Then test the new version on a copy of the Sheet with sample data before you use it for real.
