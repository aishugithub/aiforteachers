Step 1

Get your page: a file called index.html

Option A · Use the sample (for today)

A Class 7 revision page on the water cycle: four stages, key words and three self-check questions with hidden answers. See how it looks.

  1. Click Download index.html. It saves to your Downloads folder.
  2. Open it with Notepad (right-click → Open with → Notepad) and change Your Name, Your School to your own. Save.

Option B · Ask an AI to make your own page

Make a single-file HTML revision page for Class [7] students on [the water cycle]. Include: a short introduction, the key points as a numbered list, 5 key words with simple definitions, and 5 self-check questions where the answer is hidden until the student clicks (use <details>). Put all CSS inside the file, no JavaScript, no external images. It must look good on a phone. My name for the footer: [Your Name], [Your School]. Give me only the complete HTML code.
  1. Paste the prompt into Gemini, ChatGPT or Claude. Change the words in [ ].
  2. Copy the HTML it gives you. Open Notepad and paste.
  3. File → Save as. File name: index.html. Save as type: All files. Encoding: UTF-8.
  4. Double-click the file to open it in your browser and check every fact and answer, as with any AI draft.

The main page must be called index.html, all in small letters. That's the page GitHub Pages shows first.

Step 2

Make a free GitHub account

  1. Go to github.com/signup. Enter your email, a password and a username.
  2. Enter the code GitHub emails you. Skip any questions about plans: the Free plan is all you need.

Choose your username carefully. It becomes part of every link: username meenakshi-teaches gives meenakshi-teaches.github.io/…. Use one you'd happily print on a visiting card.

Step 3

Create a repository (a folder for your site)

  1. Click the ＋ at the top right → New repository.
  2. Repository name: short, small letters, no spaces, e.g. class7-science. This becomes the end of your link.
  3. Choose Public.
  4. Click Create repository.
Step 4

Upload your page

  1. On the new repository's page, click the link uploading an existing file. (Later, use Add file → Upload files.)
  2. Drag index.html into the box, or click choose your files.
  3. Scroll down and click the green Commit changes button. ("Commit" just means save.)

You should see: index.html listed in your repository.

Step 5

Turn on GitHub Pages

  1. In the repository, click ⚙️ Settings (top menu), then Pages in the left menu.
  2. Under Build and deployment, Source: Deploy from a branch.
  3. Branch: choose main and / (root). Click Save.
  4. Wait one to two minutes, then refresh the Settings → Pages screen.

You should see: "Your site is live at https://username.github.io/class7-science/" and a Visit site button. Open it on your phone too.

Step 6

Share it, update it, grow it

  • Share: post the link in Google Classroom or the class WhatsApp group. For a QR code, open the page in Chrome or Edge, right-click → Create QR code for this page.
  • Update: Add file → Upload files and upload a new index.html. It replaces the old one, and the site updates in a minute or two. The link stays the same.
  • More pages: upload chapter2.html, and it's at …/class7-science/chapter2.html. Ask the AI to add links between your pages.
  • Images: upload them too, and use exactly the same file name, capitals included, in your page.
  • A home page for you: name a repository username.github.io, and its index.html becomes https://username.github.io/: a teacher portfolio linking to all your class sites.

One page this week. A whole course by the end of the year.

Keep it safe

Everything on GitHub Pages is public

Good to publishNever publish
Revision notes, worksheets, practice quizzes with answersMarks, attendance, ranks or remarks about students
Project showcases, club or class pages (no student details)Student names with photos, phone numbers or addresses
Your own teaching material and openly licensed contentTextbook pages, or question papers before the exam

The notice-board test: if you'd pin it on the school notice board, it can go on GitHub Pages. For private things such as a marks list, use a Google Apps Script web app limited to your school (Apps Script Lab, Sample 4) or Google Classroom.

Check before you publish. An AI-made page is a draft. Verify every fact and every answer against your textbook, exactly as in today's spot-the-error demo.

Help

If something goes wrong

The link shows "404 · There isn't a GitHub Pages site here"

Wait a few minutes: the first time can take up to 10 minutes. Check that the file is called exactly index.html (small letters) and that Settings → Pages shows branch main, / (root).

The page shows code instead of a web page

The file was probably saved as index.html.txt. In Notepad, use Save as with Save as type: All files. Upload the new file, then delete the old one in GitHub (open it → ⋯ → Delete file).

My change doesn't show

Wait a minute or two, then reload with Ctrl+F5. In the repository, the Actions tab shows a green tick when the update is live.

Odd characters such as â€™ instead of quotes

Save the file in Notepad with Encoding: UTF-8, and upload it again.

I made the repository Private and Pages won't turn on

On the free plan, GitHub Pages works only with public repositories. Settings → General → scroll to Danger Zone → Change visibility → Public. Only do this if everything in it is fine to be public.

Can my school block it?

Some school networks block github.io. Test the link on the school Wi-Fi and on mobile data before sharing it with a class.
