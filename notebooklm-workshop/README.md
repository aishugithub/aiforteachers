# Gemini Notebook (formerly NotebookLM) workshop for school teachers

| File | Purpose |
|---|---|
| `slides.html` | The presentation (23 slides, including admin tasks and a Gemini Notebook vs ChatGPT/Claude comparison). Open in a browser. Keys: ←/→ move, **N** speaker notes, **F** full screen. `#s5` in the URL jumps to slide 5. |
| `hands-on-guide.html` | The hands-on lab for teachers: 14 guided steps that follow the demo, Part C admin exercises with a sample (anonymised) class list, a which-tool table, a sample source, a prompt library, practice challenges, a safe-use checklist and an FAQ. |

Public links (GitHub Pages):
- Workshop home: https://aishugithub.github.io/aiforteachers/
- Slides: https://aishugithub.github.io/aiforteachers/notebooklm-workshop/slides.html
- Hands-on guide: https://aishugithub.github.io/aiforteachers/notebooklm-workshop/hands-on-guide.html (slide 22 has a QR code to this link)

The pages use Google Fonts when online and fall back to system fonts offline.
